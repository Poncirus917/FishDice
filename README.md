# 鱼骰 FishDice

COC（克苏鲁的呼唤）跑团辅助工具，个人兴趣项目，持续开发中。  
使用**COC 7版游戏规则**。  
适用场景方面，主要考虑的是作为**网络语音团**（我和朋友平时的跑团形式）**的辅助**。也会针对文字团、秘密团等情况进行优化。       
能力所限，无法覆盖到所有的COC 7版规则；考虑到玩家体验，跑团的规则设定也应当有一定自由度。没有覆盖到的规则应该也可以由守秘人与玩家简单地手动处理。  
基本上完全是AI写的，我本人不懂相关知识，也没有相关经验。以后会学习。  

> 大多数内容主要是在考虑我与朋友的体验，我知道已经有成熟的线上跑团平台，也知道这个网页很可能这辈子都只会被我们三个人打开，我本人也无意让该网页有个人娱乐以外的其他用途。  
> 但我希望让它达到一个自己心中的标准：假设有其他的COC跑团玩家发现并想要使用鱼骰，它的功能一定要是合格的。因此我会不断优化它，直到我自己满意。  
> 在此感谢两位朋友的测试和反馈。  
> 叫鱼骰是因为朋友们平时叫我“鱼鱼”，以及和“鱼头”谐音，而且COC跑团里会出现鱼人这种怪物。~~这种东西有什么解释的必要…~~

## 单机版

供单人使用的本地掷骰工具，无需登录，打开即用。  
功能已基本完成，除非发现有bug不会再改动。

### 功能

- **角色导入与管理**：支持PC、NPC、怪物三种类型，文本解析一键导入，可编辑、删除
- **掷骰判定**：技能/属性检定、自由掷骰，结果自动判定
- **规则联动**：HP/SAN变化时自动触发重伤、濒死、死亡、临时疯狂等状态判定
- **特殊规则**：燃烧幸运、孤注一掷、幕间成长
- **记录导出**：实时记录所有掷骰与状态变化，可导出为 TXT 文件

## 联机版

支持多人在线联机的跑团平台，正在开发中，更新速度不定。  
目前房间创建与角色管理功能已基本成型，有简单的掷骰模块，但暂未完善到能完全支持跑团活动。  
在功能基本完善后，会考虑对页面进行美化。  
**若要同时登录多个账号，请使用不同的浏览器。**

## 技术栈

- **前端**：Next.js + TypeScript + Tailwind CSS v4
- **后端**：Supabase（Auth + PostgreSQL + Realtime + Storage）
- **部署**：Cloudflare Pages

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

联机版需要配置 Supabase 环境变量，参考 `.env.example`。
